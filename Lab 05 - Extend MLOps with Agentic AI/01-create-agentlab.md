## Overview

In this step, you will create an AI agent using AgentLab in watsonx.ai. This agent will enable users to query customer repurchase predictions using natural language.

---

## 1.1 Access Your Project

1. Click **Hamburger icon** in top left
2. Expand **Projects**
3. Click **View all projects**

<img width="268" height="284" alt="image" src="https://github.com/user-attachments/assets/6822bf77-ad8c-4903-be04-d61c470dbfec" />

4. Select your latest project
5. Click **Assets** tab

---

## 1.2 Create Agent Asset

1. Click **New Assets** button <img width="114" height="27" alt="image" src="https://github.com/user-attachments/assets/f78c15ec-674d-4d93-a272-172441e30d0c" />
2. Type **"agent"** in search field
3. Select **Build an AI agent to automate tasks**

<img width="1607" height="441" alt="image" src="https://github.com/user-attachments/assets/e53b55cd-a36e-4e4f-8268-bac4bc6de3bf" />

---

## 1.3 Configure Agent Setup

1. In Setup section, set:
   - **Name**: `Repurchase Agent`
   - **Description**: `Agent to get prediction about customer repurchase transaction`

<img width="900" height="257" alt="image" src="https://github.com/user-attachments/assets/d958e3cd-cf29-433f-8ce7-eab33ab6f9bd" />

---

## 1.4 Configure Advanced Settings

1. Download file **assets/prompt.txt** from the lab directory

2. Scroll down to **Configuration** section
3. Click **Advanced Configuration** <img width="161" height="20" alt="image" src="https://github.com/user-attachments/assets/b4dd3001-ed7c-4762-9fc2-7a07ee7dcdd9" />
4. Copy content from **prompt.txt** file
5. Paste it into the configuration field
6. Click **Apply** button

<img width="1769" height="888" alt="image" src="https://github.com/user-attachments/assets/d856ba4b-d237-4964-a604-95db356fd374" />

---

## 1.5 Save Agent

1. Click **Save icon** <img width="25" height="25" alt="image" src="https://github.com/user-attachments/assets/008cea64-97e9-49b3-920f-616425dbde80" />
2. Click **Save As**
3. Select **Agent** as Asset type
4. Click **Save** button

<img width="1783" height="900" alt="image" src="https://github.com/user-attachments/assets/851ef9e2-9864-4d83-8990-e4b7a9358d6d" />

5. Ensure **Autosave** slider is on <img width="132" height="30" alt="image" src="https://github.com/user-attachments/assets/64effbae-321e-40c4-85de-bad114e826a6" />

---

## Agent Created

You have successfully created an AgentLab agent that will:
- ✅ Accept natural language queries
- ✅ Process customer repurchase prediction requests
- ✅ Use custom tools to retrieve data and make predictions
