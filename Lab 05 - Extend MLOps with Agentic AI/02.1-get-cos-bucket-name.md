# Get IBM Cloud Object Storage (COS) Bucket Name

[← Back to Step 2: Create Python Function](./02-create-python-function.md)

---

## Overview

This guide helps you find your COS bucket name where the FEATURE_STORE.csv file is stored.

---

## Steps to Get Bucket Name

### 1. Access Import Asset

1. Go to your project **Asset** tab
2. Click **Import Asset** button

<img width="1728" height="542" alt="image" src="https://github.com/user-attachments/assets/6d413d00-a99a-4a7a-b2e7-cbbe68da9701" />

---

### 2. Navigate to COS Connection

1. Click **Connected data**
2. Click **cos-connection**
3. Select the bucket where you stored your feature store
4. Click **Copy icon** to copy the bucket path

<img width="1620" height="507" alt="image" src="https://github.com/user-attachments/assets/8a7d7ee8-ec1a-4bb7-a7ae-41734f3d9b72" />

---

### 3. Extract Bucket Name

1. The copied value will be in format: `/bucket-name`
2. Remove the leading slash (`/`) to get the actual bucket name

**Example:**
- Copied value: `/repurchasemodel-donotdelete-pr-spincdlcpmf5ao`
- Actual bucket name: `repurchasemodel-donotdelete-pr-spincdlcpmf5ao`

---

## Use the Bucket Name

Use this bucket name as the value for the `COS_BUCKET_NAME` secret in [Step 2.4](./02-create-python-function.md#24-configure-secrets).
