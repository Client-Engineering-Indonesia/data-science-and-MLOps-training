# Get IBM Cloud Object Storage (COS) Bucket Name

1. Go back to your project Asset tab --> click Import Asset button

<img width="1728" height="542" alt="image" src="https://github.com/user-attachments/assets/6d413d00-a99a-4a7a-b2e7-cbbe68da9701" />

2. Click Connected data --> click cos-connection --> select which bucket that you stored your feature store --> click Copy icon --> save it somewhere and remove slash character (/) to get actual bucket name. For example if you copied `/repurchasemodel-donotdelete-pr-spincdlcpmf5ao` then your bucket name i.s `repurchasemodel-donotdelete-pr-spincdlcpmf5ao`.
