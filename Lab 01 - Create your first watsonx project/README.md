# Lab 01: Create Your First watsonx Project

This lab guides you through setting up your first IBM watsonx project, including creating necessary connections to databases and cloud storage.

---

## Overview

In this lab, you will:
- Access the IBM watsonx platform
- Create a watsonx API key for authentication
- Set up a new watsonx project
- Associate watsonx services with your project
- Configure database and storage connections

---

## Prerequisites

Before starting this lab, ensure you have:
- Received your IBM Cloud credentials (username, password, and login URL)
- Access to IBM watsonx platform
- Basic understanding of cloud services

---

## Lab Steps

### [Step 1: Access watsonx Platform](./01-access-watsonx-platform.md)
Learn how to sign in to IBM Cloud and launch the watsonx platform.

### [Step 2: Create watsonx API Key](./02-create-watsonx-api-key.md)
Generate an API key for programmatic access to watsonx services.

### [Step 3: Create watsonx Project](./03-create-watsonx-project.md)
Set up your first watsonx project workspace.

### [Step 4: Associate watsonx Service](./04-associate-watsonx-service.md)
Link watsonx services to your project for AI/ML capabilities.

### [Step 5: Create Db2 Database Connection](./05-create-db2-connection.md)
Configure a connection to IBM Db2 database for data access.

### [Step 6: Create Cloud Object Storage Connection](./06-create-cos-connection.md)
Set up Cloud Object Storage (COS) connection for file storage and management.

---

## Expected Outcomes

By the end of this lab, you will have:
- ✅ Successfully accessed the watsonx platform
- ✅ Created a watsonx API key
- ✅ Set up a new watsonx project named "Churn Model"
- ✅ Associated watsonx services with your project
- ✅ Configured Db2 database connection
- ✅ Configured Cloud Object Storage connection
